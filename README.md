# 프롬프트 관리 프로그램

콘솔(터미널) 기반으로 동작하는 AI 프롬프트 관리 프로그램입니다
자주 사용하는 프롬프트를 카테고리별로 저장하고, 검색하고, 즐겨찾기로 관리할 수 있습니다

## 주요 기능

- **프롬프트 추가**: 제목, 내용, 카테고리를 입력하여 새 프롬프트 등록
- **전체 목록 보기**: 등록된 모든 프롬프트를 한눈에 확인
- **카테고리별 조회**: 원하는 카테고리에 속한 프롬프트만 필터링하여 조회
- **키워드 검색**: 제목이나 내용에 특정 키워드가 포함된 프롬프트 검색
- **상세 보기**: 선택한 프롬프트의 제목, 카테고리, 즐겨찾기 상태, 전체 내용 확인
- **즐겨찾기 관리**: 프롬프트를 즐겨찾기에 추가/해제하고, 즐겨찾기 목록만 따로 조회

## 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 실행
```
===== 프롬프트 관리 프로그램 =====
1. 프롬프트 추가
2. 프롬프트 목록 보기
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
0. 종료
==================================
```

## 기본 제공 프롬프트

프로그램을 처음 실행하면 예시로 아래 3개의 프롬프트가 자동으로 등록되어 있습니다.

| 제목 | 카테고리 | 즐겨찾기 |
|---|---|---|
| LLM 모델 비교 및 선정 | 텍스트 생성 | ☆ |
| 인스타툰 캐릭터 홍보 영상 소스 제작 | 이미지 생성 | ★ |
| 자동화 워크플로우 설계 | 자동화 | ☆ |

## 코드 구조

| 함수 | 설명 |
|---|---|
| `get_default_prompts()` | 초기 예시 프롬프트 데이터 생성 |
| `show_menu()` | 메인 메뉴 출력 |
| `input_nonempty()` | 빈 값 입력 방지 헬퍼 함수 |
| `choose_category()` | 카테고리 선택 또는 직접 입력 처리 |
| `add_prompt()` | 새 프롬프트 추가 |
| `format_prompt_line()` | 목록 출력용 한 줄 포맷 생성 |
| `show_list()` | 전체 프롬프트 목록 출력 |
| `show_by_category()` | 카테고리별 필터링 조회 |
| `search_prompt()` | 키워드 기반 검색 |
| `show_detail()` | 프롬프트 상세 정보 출력 |
| `manage_favorites()` | 즐겨찾기 추가/해제 및 목록 조회 |
| `main()` | 메뉴 반복 실행 (프로그램 진입점) |
